# PhantomArmorPluginV2
Simple Spigot plugin to REALLY spice up your minecaft server

PHANTOM ARMOR

A Paper plugin for Minecraft 1.21.4 with craftable Phantom Armor and abilities

# FEATURES

Craft Phantom Essence and Phantom Armor

Each armor piece unlocks an ability

Press F with an empty hand to change abilities

Right click with an empty hand to use abilities

Ability selection and cooldowns appear in chat

Each armor piece can only be crafted once per player

# ABILITIES

Phantom Sight reveals nearby players

Phantom Surge gives Speed III and Strength III for 20 seconds

Phantom Dash launches the player forward

Phantom Dive needs the full armor set and 7 blocks of height then sneak to activate it

Phantom Cloak makes the player invisible until they attack break a block or interact

# CONTROLS

Wear Phantom Armor

Select an empty hotbar slot

Press F to change ability

Right click for Sight Surge Dash and Cloak

For Dive select Dive jump at least 7 blocks high then sneak

INSTALLATION

Use a Paper server for Minecraft 1.21.4

Put the PhantomArmor jar file in the server plugins folder

Restart the server

# COMMANDS

/phantomarmor help

phantomarmor give player all helmet chestplate leggings boots essence

# CRAFTING

PHANTOM ESSENCE

4 Phantom Membranes in the corners

4 Amethyst Shards on the edges

1 Echo Shard in the center

# PHANTOM ARMOR

Use a crafting table

32 Phantom Membranes in every corner

Phantom Essence on each edge

Matching Netherite armor piece in the center

# CONFIGURATION

Change cooldowns durations and ability values in the PhantomArmor config file
